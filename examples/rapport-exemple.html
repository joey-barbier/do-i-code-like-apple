Top 3 — fixes 5 minutes

Les plus rentables d'abord. Chaque fix : avant, après, et la doc Apple qui l'explique.

1 · Sortir le tri du body du dashboard 5 MIN

Avant
List(store.projects
  .sorted { $0.criticality > $1.criticality }) { … }
Après
// Store :
var projects: [Project] = [] {
  didSet { sorted = projects.sorted { … } }
}
// Vue :
List(store.sorted) { … }
→ Managing model data in your app

2 · Equatable sur les structs d'état 1 MOT

Avant
struct CheckoutState {
  var step = 0; var isPaying = false
}
Après
struct CheckoutState: Equatable {
  var step = 0; var isPaying = false
}
→ Observation

3 · Fixtures de tests en #require 5 MIN

Avant
let item = catalog.first { $0.id == "core" }!
// échec = crash de TOUT le run
Après
let item = try #require(
  catalog.first { $0.id == "core" })
// échec = UN test rouge, le run continue
→ Swift Testing
